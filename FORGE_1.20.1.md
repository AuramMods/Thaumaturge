# Thaumaturge on Minecraft Forge 1.20.1

## Install

Use a Minecraft Java Edition **1.20.1** instance with **Forge 47.4.10 or later within the 47.x series** and **Java 17**. The Auram compatibility tests use Forge **47.4.10** and Temurin **17.0.18**. [Forge 1.20.1 downloads](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)

Place these three runtime JARs in the instance's `mods` directory. For multiplayer, install the same versions on the server and each client.

| Required mod | Tested version |
| --- | --- |
| Thaumaturge | `thaumaturge-1.1.3.jar` |
| Curios API | [5.14.1+1.20.1](https://modrinth.com/mod/curios/version/5.14.1%2B1.20.1) |
| Lithostitched | [1.4.11-forge-1.20](https://modrinth.com/mod/lithostitched/version/srPoHKt8) |

The optional Jade integration is built against Auram's [Jade 11.13.2 for Forge](https://modrinth.com/mod/jade/version/LecuGude).

Start the Forge profile and create a fresh world. On a dedicated server, use the `run.sh` or `run.bat` script generated by the Forge installer. Join with the matching client profile. See the [dependency matrix](PORTING_1.20.1.md#dependencies-and-integrations) for version pins and evidence for each optional integration.

Thaumaturge's Misc Toggle and Curios' Open Curios Inventory both default to `G`, as they did on the 1.21.1 baseline. In the Minecraft key bindings screen, assign one of them an unused key to use both shortcuts independently.

On Apple Silicon, the combined optional renderer profile produced an intermittent native Metal crash during a cached-profile restart. The same native stack occurred in the control with Thaumaturge absent. Fresh client profiles completed the combined replay, and the dedicated Distant Horizons fog test passed. [Runtime evidence](PORTING_1.20.1.md#cycle-425-evidence-and-next-work)

## Build

From a checkout of the `1.20.1` branch, use a Java 17 JDK and the Gradle wrapper. A Java 21 Gradle JVM also works with an installed Java 17 toolchain. Run resource generation and packaging in separate invocations.

```sh
./gradlew runData
./gradlew jarJar
```

The distributable is `build/libs/thaumaturge-1.1.4-mc1.20.1-forge.jar`. On macOS, calculate its SHA-256 with the following command. On Linux, use `sha256sum` with the same path.

```sh
shasum -a 256 build/libs/thaumaturge-1.1.4-mc1.20.1-forge.jar
```

Rebuilds can differ in ZIP timestamps even when every payload is identical. [Auram compatibility results](PORTING_1.20.1.md#cycle-439-auram-dependency-compatibility), [Distant Horizons client verification](PORTING_1.20.1.md#cycle-440-distant-horizons-client-compatibility)

## Verify

After `runData`, run the original Forge suite, focused client and server suites, and in-world GameTests together.

```sh
./gradlew -PportHiddenWindow -PportIntegrations build
```

Gradle writes the reports under `build/test-results/`. On CI hosts without a display, use the software OpenGL and Xvfb command in the [build workflow](.github/workflows/build.yml).

For an unattended development client, use `./gradlew -PportHiddenWindow runForgeBackgroundClient`. It starts in its own profile with sound muted, narration off and the window hidden. For interactive testing, use `./gradlew runClient` and click the window when you are ready for it to receive input. See the [background testing guide](porting/testing/README.md).

For a packaged smoke test, start a clean Forge server with the three runtime JARs and join from a matching client. Open a fresh Survival world, collect a generated primal crystal, sleep for the dream journal, and use Salis Mundus on a bookshelf to obtain the Thaumonomicon. Craft and use a Thaumometer, save, and reopen the world to verify that research persists. The [acceptance matrix](PORTING_1.20.1.md#feature-and-acceptance-matrix) links the full progression, persistence, multiplayer and integration checks.

The 1.1.1 audit reconciles 16 passing feature areas and 2,748 passing cases across the original suite, focused Forge suites, and native GameTests. That JAR passed packaged Survival progression through the Outer Lands, two-player restart and reload tests, and optional Oculus and moving Sable ship replays. Version 1.1.2 targets Auram's original dependency versions, passes the world's registry lookup to KubeJS recipe workers, and preserves the original biome source when saving.
